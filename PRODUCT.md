# Product Specification: Raveesha's 21st Birthday Celebration ("Baba's Birthday")

## 1. Product Overview
An interactive, luxury digital invitation web application celebrating Raveesha's (Baba's) 21st birthday. Designed to deliver an immersive, personal, and memorable experience for guests before the event.

## 2. Core Purpose & Target Audience
- **Target Audience:** Close friends, family, and loved ones invited to celebrate.
- **Core Goal:** Inform guests of all event details (time, venue, timeline), build excitement with interactive multimedia, and streamline RSVP management directly into Google Sheets.
- **Emotional Tone:** Romantic, elegant, celebratory, warm, and personal.

## 3. Key Feature Specifications
1. **Interactive Wax-Sealed Envelope Reveal:**
   - Envelope intro with clickable wax seal stamp.
   - Seamless transition into the main celebration paper-strip invitation.
2. **Atmospheric Visuals:**
   - Floating sakura petals drifting naturally across the viewport.
   - Animated butterflies (white and pink) fluttering organically.
   - Fluid rose mesh gradient background.
   - Custom heart/sparkle cursor for desktop interaction.
3. **Hero & Celebration Showcase:**
   - Prominent birthday title and age milestone badge ("21").
   - Emotional quote card with vintage floral flourishes.
4. **Interactive Media & Timeline:**
   - Vintage vinyl record music player with toggleable track playback.
   - Live real-time countdown timer to the celebration date and mini calendar view.
   - Visual step-by-step event timeline.
   - Curated photo gallery memory carousel.
5. **Guest Utilities:**
   - Full event details (date, dress code, venue location).
   - Venue map preview & directions link.
   - Interactive RSVP modal/form with automated submission to Google Sheets.

## 4. Technical Constraints
- **Stack:** React 19, Vite, Framer Motion, Lucide Icons, Vanilla CSS.
- **Responsiveness:** Flawless layout on modern mobile devices (iOS Safari, Android Chrome), tablets, and desktop displays.
- **Performance:** Fast asset delivery, smooth 60fps animations without layout thrashing.
